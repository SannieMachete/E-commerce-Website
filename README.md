# E-commerce-Website
Star Luxury Boutique is a fully functional, single-page e-commerce website built with HTML, CSS, and JavaScript. Designed for a South African luxury fashion retailer, it delivers a premium shopping experience with a clean editorial aesthetic.
Key Features

Product Listing — 12 curated fashion items displayed in a responsive grid, each with category badges (New, Sale, Bestseller), pricing, and product imagery.
Search & Filter — Live search by product name or keyword, category filter tabs (Tops, Bottoms, Outerwear, Accessories), and sorting by price or name.
Shopping Cart — A slide-out cart drawer with full quantity controls, item removal, and a running subtotal. Free shipping is automatically applied on orders over R1 500.
Checkout UI — A multi-section checkout modal covering contact details, shipping address, and payment (Card, SnapScan, EFT), with a full order summary breakdown.
Order Confirmation — A success screen with a unique order reference number generated on placement.
Persistent Cart — Cart data is saved to localStorage so items are retained across page refreshes.

Tech Stack
Built entirely with HTML5, CSS3, and vanilla JavaScript — no frameworks, no dependencies, no backend required. Prices are displayed in South African Rand (R) and the store is localised for a South African audience.
